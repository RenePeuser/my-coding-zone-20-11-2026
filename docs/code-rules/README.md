# CodeRules

One page per rule. Stage 2 (`src/MyCodingZone.CodeRules.Test`) and stage 5 (`src/MyCodingZone.CodeRules`) share the IDs,
every finding links to the page of its rule.

|---|---|---|
| [PROJECTS_RULE_001](PROJECTS_RULE_001.md) | Projects | Productive projects must not reference test projects |

| [RECORDS_RULE_002](RECORDS_RULE_002.md) | Records | Records must not implement methods |
| [SERVICES_RULE_001](SERVICES_RULE_001.md) | Services | Each service needs a registration extension in the same file |
| [SERVICES_RULE_002](SERVICES_RULE_002.md) | Services | Each service registration has to be called |
| [SERVICES_RULE_003](SERVICES_RULE_003.md) | Services | Inject multiple implementations as IEnumerable&lt;T&gt; |
| [SERVICES_RULE_004](SERVICES_RULE_004.md) | Services | A service registration registers the dependencies of the service |
| [SERVICES_RULE_005](SERVICES_RULE_005.md) | Services | Service registrations return void |
| [SERVICES_RULE_006](SERVICES_RULE_006.md) | Services | Services inject at most 5 dependencies |
| [SERVICES_RULE_007](SERVICES_RULE_007.md) | Services | Each service registration has to register the service itself |
